# Web Scraping and Data Analysis Project
🚀 Web Scraping & Data Analysis Project 📚

Completed a Python-based Web Scraping project using:

✅ BeautifulSoup
✅ Requests
✅ Pandas
✅ Matplotlib & Seaborn

🔍 Project Overview:

* Extracted 1000+ book records from the “Books to Scrape” website
* Collected:
  • Book Titles
  • Prices
  • Ratings
  • Stock Availability

📊 Performed Exploratory Data Analysis (EDA):

* Price Distribution Analysis
* Rating Distribution Visualization
* Price vs Rating Comparison
* Stock Availability Insights
* Statistical Summary & Data Cleaning

📈 Visualizations Created:
✔ Histogram
✔ Bar Chart
✔ Pie Chart
✔ Box Plot
✔ Violin Plot

🛠 Technologies Used:
Python | BeautifulSoup | Pandas | NumPy | Matplotlib | Seaborn

📁 Dataset Generated:
Custom CSV dataset created from scraped website data for further analysis and machine learning applications.
